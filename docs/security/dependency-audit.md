## resolutions

`resolutions` ставятся только для high и critical, достижимых в production-рантайме, когда патч вне диапазона зависимого, а upstream отстаёт. Среди записей остатка таких нет, добавленных ключей нет. В корневом `package.json` `resolutions` содержит только `@types/react` и `@types/react-dom`.

Категории достижимости:

- production-рантайм: код пакета исполняется в web или server во время работы;
- build-инструмент: исполняется только при установке или сборке;
- dev-инструмент: только через devDependencies;
- не поставляется: пакета нет в выкладке.

tar 6.2.1, http-cache-semantics 4.2.0 и serialize-javascript 6.0.2 есть и в `yarn npm audit --all --recursive --environment production --severity high --json`, потому что `bcrypt` и `webpack` стоят в dependencies app/web. Их код во время работы web и server не исполняется.
