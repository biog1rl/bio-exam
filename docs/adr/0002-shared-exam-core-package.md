# ADR-0002: Доменная логика экзамена живёт в общем пакете `packages/exam-core`

Поведение шаблона вопроса описано примерно в 11 местах двух приложений. Сюда входят форма ключа ответа, форма ответа студента, проверка «отвечено ли», нормализация, оценка и вердикт по каждой части ответа. Копии уже разошлись:

- Последовательность `1234` при правильной `1243` сервер считает одной ошибкой (соседняя перестановка), а экран разбора пишет «Совпало позиций: 2/4».
- Валидация на странице редактора вопроса ждёт для `short_text` строку, а вопрос с несколькими допустимыми вариантами хранит массив.

В `web/lib/tests/types.ts` прямо написано «Keep in sync manually (no shared package)».

## Решение

- **Пакет `packages/exam-core`.** Это чистый TypeScript, из зависимостей только `zod`. Пакет собирается так же, как `@bio-exam/rbac`.
- **Один адаптер на шаблон вопроса:** `single_choice`, `multi_choice`, `matching`, `short_text`, `sequence_digits`. Каждый адаптер отвечает за форму ключа и её проверку при авторинге, форму ответа, «отвечено ли», нормализацию, подсчёт ошибок и вердикты по частям для экрана разбора.
- **Контракты.** В пакете объявлен формат результата попытки (zod-схема) и слияние телеметрии. Всё, что пересекает HTTP между `app/web` и `app/server`, объявляется в пакете и импортируется, а не копируется.
- **Кто использует пакет.** Редактор вопросов, прохождение теста, разбор попытки и сервер (валидация при сохранении и оценка при submit) работают через него.

## Последствия

- Правила шаблонов правятся в одном месте. Новый шаблон — это новый адаптер.
- Тесты пакета табличные: (ключ, ответ) → оценка и вердикты по частям, плюс инвариант «все части верны ⇔ ошибок 0». Эти таблицы становятся точкой отсчёта для дальнейшего рефакторинга.
- Пакет не тянет React, Lexical, Drizzle или Tiptap.
