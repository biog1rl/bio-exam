## D2: метрика последовательности

### Какая метрика остаётся (D-05)

| Option | Description | Selected |
|--------|-------------|----------|
| Серверная `hamming_digits` как есть | Позиционные несовпадения + разница длин; одна соседняя перестановка при длине > 3 — одна ошибка. Ею оценены все сабмиты после деплоя `04c621c` (коммит 2026-07-25) | ✓ |
| Чисто позиционная (как сейчас в разборе) | Совпадает с сабмитами до `04c621c`, но меняет баллы новых сабмитов (соседняя перестановка: 1 балл → 0) и противоречит тестам `scoring.test.ts:155-165` | |
| По инверсиям (Kendall tau) или Damerau | Новая метрика: меняет баллы во многих случаях, расходится со всеми сохранёнными оценками | |

**Принято автономно:** серверная метрика как есть.
**Notes:** `app/server/src/lib/tests/scoring.ts:145-170`; правило добавлено коммитом `04c621c` (2026-07-25, дата деплоя неизвестна), до него сервер считал чисто позиционно. Длина ≤ 3: перестановка — две ошибки (`scoring.test.ts:200-209`, `:244-255`).
