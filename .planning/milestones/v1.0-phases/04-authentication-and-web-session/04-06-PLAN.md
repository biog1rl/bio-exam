<objective>
Привязать access-токен к отзываемой серверной сессии и собрать выдачу сессии в один модуль (D-05, D-06, D-07 атомарный захват, D-08 выход, D-09, D-10): вход создаёт сессию, refresh атомарно захватывает токен и ставит cookie только после commit, выход отзывает сессию, запрос принимается только с живой сессией.

Purpose: закрывает 30-дневное окно access-токена (AUTH-04), гонку двух refresh на уровне базы (AUTH-05, окно повтора и replay добавляет 04-07) и три копии чтения и склейки cookie (AUTH-07). Tracer — вход → sid в токене → проверка сессии → refresh через модуль → выход → старый access отклонён.
Output: модуль `services/session`, правки `config/auth.ts`, `session.ts`, `login.ts`, `refresh.ts`, `logout.ts`, `test-support/http.ts` и его вызывающих, тест ротации, переключённые AUTH-04 (Vitest и e2e).
</objective>
