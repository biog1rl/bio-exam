## Решения пользователя (2026-10-05)

- **CR-01.** Плашка «Не удалось отправить — Повторить» после неудачного повтора отправки при восстановлении показывается всегда: и после автосдачи по таймеру, и после ручного «Завершить», как при сбое без перезагрузки.
- **CR-11.** Новый вопрос, появившийся в тесте во время прохождения, модуль принимает на лету: список вопросов обновляется, ответ на новый вопрос сохраняется.
- **CR-04.** «Завершить» без сессии, при этом на сервере уже есть черновик этой сессии с другого устройства: черновик сервера сливается с локальными ответами (локальные важнее, как при восстановлении, D-12), затем идёт отправка.
