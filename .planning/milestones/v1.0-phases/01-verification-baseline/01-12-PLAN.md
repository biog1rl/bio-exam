<task type="auto">
  <name>Task 1: Dump comparison script with a self-test</name>
  <files>scripts/compare-schema-dump.mjs</files>
  <read_first>scripts/lib/test-db.mjs, app/server/drizzle/migrations-manifest.json, .planning/phases/01-verification-baseline/01-RESEARCH.md (sections "Pattern 11", "Pitfall 13")</read_first>
  <action>
Implements the tooling half of D-07. Zero dependencies; local only (needs `pg_dump` 17 from `findPgBin()`).
1. CLI: `node scripts/compare-schema-dump.mjs --prod <dump.sql> [--prod-meta <meta.txt>] --report <report.md>` and `node scripts/compare-schema-dump.mjs --self-test`.
2. Main path: `withTestDatabase('test_d07', ...)`, migrate with the real runner (`yarn workspace @bio-exam/server drizzle:migrate`, `isolatedChildEnv`), then dump the scratch database with `<pgbin>/pg_dump --schema-only --schema=public --schema=extensions --no-owner --no-privileges`. Pass the scratch URL to pg_dump only via the `--dbname` argument; never print it.
3. `normalize(text)`: drop lines starting with `--`, blank lines, lines starting with `\restrict ` or `\unrestrict `, and the session preamble (`SET ...;`, `SELECT pg_catalog.set_config(...)`); trim trailing whitespace.
4. Diff: write both normalised texts to a temp dir and run `diff -u prod.sql chain.sql` (exit 1 means differences, which is not an error). Build the report as Markdown in Russian: date, `pg_dump --version`, line counts, then the diff in a fenced `diff` block. A classification table lists each hunk as `шум платформы` (publication `supabase_realtime`, default privileges, Supabase-only schemas or roles, extension placement) or `реальное отличие`; unclassifiable hunks default to `реальное отличие`.
5. `--prod-meta`: parse lines for timezone, `datcollate datctype` and `hash created_at` rows. Report the timezone and collation, and whether the set of live hashes equals the manifest sha256 list (missing / extra hashes listed).
6. `--self-test`: two scratch databases, both migrated; dump one as "prod" and compare. The diff must be empty and the run prints `compare-schema-dump self-test: OK`.
  </action>
