Implements D-18 (local mode, interface unchanged, containment from day one) and D-17 (no Supabase from isolated processes). Before editing, run `codegraph impact StorageService` and `codegraph impact storageService` and list the callers in the SUMMARY.
1. Read the configuration lazily at call time, so tests can set it: `STORAGE_DRIVER` (`local` enables the mode) and `STORAGE_LOCAL_DIR` (must be an absolute path; otherwise throw `STORAGE_LOCAL_DIR must be an absolute path`). Add a module-level `isLocalStorage()`.
2. `resolveLocalPath(key, { forWrite })`: reject an empty key, NUL, a leading `/` or `\`, a drive letter `^[A-Za-z]:`, any backslash, and any `..` segment after `path.posix.normalize`. Then `abs = path.resolve(root, key)` and `rel = path.relative(root, abs)`; reject when `rel === ''`, `rel.startsWith('..')` or `path.isAbsolute(rel)`. Never use a bare `startsWith(root)` comparison. For reads, `fs.realpath(abs)` must stay under `fs.realpath(root)`. For writes, the realpath of the deepest existing ancestor must stay under `fs.realpath(root)` (symlink escape). Throw `Error('[StorageService] path escapes storage root')` without echoing absolute host paths beyond the key.
3. Add a local branch at the top of `readFile`, `readFilesParallel`, `writeFile` (write to `<abs>.tmp-<random>` then `fs.rename`), `writeJson`, `readJson`, `uploadBuffer`, `downloadBuffer` (content type from an extension map: png, jpg/jpeg, gif, webp, svg, md, json, txt, zip; default `application/octet-stream`), `deleteFiles` (ignore ENOENT), `listFiles` (direct entries, sorted, `${prefix}/${name}`), `listFilesRecursive` (files only, `/` separators, sorted) and `exists`. `deleteDirectory` keeps using `listFilesRecursive` + `deleteFiles`.
4. Keep `isConfigured()` meaning "Supabase configured". `routes/docs/assets.ts`, `routes/users/avatar.ts` and `routes/tests/index.ts` branch on it and keep their own code paths (ADR-0004 moves them in Phase 7).
