<objective>
Make DRZ-01 true and machine-checkable. Build the comparator that proves the migration chain and `schema.ts` describe the same database, then correct `schema.ts` (D-28) until the comparator reports no differences, with no new migration.

Purpose: research C3 measured that the chain does not produce `schema.ts`. The differences are 10 `timestamptz` columns, RLS with 25 policies, index names, 3 undeclared indexes, FK/PK names and DESC columns. The `timestamp()` mismatch is also a runtime bug on non-UTC sessions. Comparing schema.ts by pushing it at a database is forbidden here. The gate therefore materialises both sides in throwaway `test_*` databases and diffs their catalogs, so both sides are canonicalised by the same PostgreSQL server.
Output: `scripts/lib/schema-fingerprint.mjs`, `scripts/check-migrations.mjs` (comparison stage), server DB-test helpers, the timestamptz regression test and the corrected `schema.ts`.
</objective>
