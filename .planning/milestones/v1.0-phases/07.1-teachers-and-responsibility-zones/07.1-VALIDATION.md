## Test Infrastructure

| Свойство | Значение |
|----------|----------|
| **Фреймворки** | Vitest (server, rbac), `node:test` для проверок репозитория в `scripts/`, Playwright (e2e) |

| RBAC | `yarn workspace @bio-exam/rbac vitest run <файл>` |
| GUARD | `node --test scripts/<файл>` |
| E2E | `yarn e2e tests/<файл>.spec.ts` (сценарий учителя: 9 тестов на chromium-desktop и chromium-mobile) |
