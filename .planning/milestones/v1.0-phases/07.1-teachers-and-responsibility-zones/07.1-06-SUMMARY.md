## Формулы

```typescript
zoned(req, key, inZone): нет req.authUser → false; нет key → false; zone.all → true; иначе inZone(userId)
canReadTest      = zoned('tests.read',  topicOfTest(testId) ∈ myTopicIds)
canWriteTest     = zoned('tests.write', topicOfTest(testId) ∈ myTopicIds)
canWriteTopic    = zoned('tests.write', topicId ∈ myTopicIds)
canReviewAttempt = zoned('tests.read',  topicOfAttempt(attemptId) ∈ myTopicIds)
canReadUser      = zoned('users.read',  isMemberOfOwnedGroup(userId, targetId))
testScope        = нет пользователя или tests.read → { all: false, topicIds: [] }; zone.all → { all: true }; иначе { all: false, topicIds: [...myTopicIds] }
```

`myTopicIds` — мемоизация разделов на Request из 07.1-03; несуществующий объект (`null` от загрузчика) без `zone.all` → `false`.
