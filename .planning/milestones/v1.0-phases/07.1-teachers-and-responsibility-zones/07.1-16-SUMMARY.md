# Phase 07.1 Plan 16: EditUserDialog с несколькими группами и предупреждениями о зоне Summary

Администратор задаёт ученику несколько групп одним сохранением: поле «Группа» в `EditUserDialog` стало мультивыбором (`Popover` + `Command`, `Check` у выбранных, суффикс « · {владелец или администраторы}»), сохранение шлёт `PATCH /api/users/:id/group { groupIds }` полным набором только при изменении набора. ## Решения исполнителя (автономно)

1. **`deactivating` — переход.** Предупреждение о передаче зоны при деактивации показывается, когда пользователь был активен и отметка «Активирован» снята (формулировка UI-SPEC «снята отметка»). Сервер освобождает зону при любом `isActive: false` в теле; уже деактивированный учитель зоны не держит (закрепить тему и владение группой за неактивным сервер не даёт), поэтому повторное предупреждение при каждом открытии такого пользователя было бы шумом.
2. **`to` без смены роли равно `from`.** Диалог показывает первую валидную роль; у пользователя с ролями user и teacher это user. Без смены роли `roles` в тело не попадает и сервер зону не трогает, поэтому и предупреждения нет.
3. **`initialOwnsZone`** с ролью, для которой нет признака или признак `null`, возвращает `null`, если ни одна роль не дала `true`: предупреждения нет, решает сервер.
4. **`roles` при отсутствии исходной роли.** Если у пользователя не было валидной роли и администратор её выбрал, `roles` уходит (иначе выбор терялся бы). Если роль не выбрана, кнопка «Сохранить» выключена, как раньше.
5. **Ошибка групп.** 400 сервера («В группу учителя можно добавить только учеников», «Деактивированного ученика нельзя добавить в группу») и 404 «Группа не найдена» показываются текстом из тела; без `error` — прежний текст «Не удалось обновить группу».
6. **Исходные значения после частичного сохранения.** Если профиль сохранён, а группы нет, диалог остаётся открытым с ошибкой; исходные роль, роли и активность уже обновлены, повторное «Сохранить» не шлёт `roles` повторно и не сбрасывает персональные права ещё раз.
7. **Без поиска в списке групп.** В UI-SPEC для этого поля нет текста `CommandInput` и `CommandEmpty`, тексты берутся только из UI-SPEC; список прокручивается (`max-h-60`).
8. **Без иконки в новых Alert:** UI-SPEC иконку не задаёт.
