## Формы ответов

- `GET /api/tests/topics`: `{ topics: Array<{ id, slug, title, description, order, isActive, createdAt, testsCount }> }`; при `canManageCatalog` у каждой строки ещё `teachers: Array<{ id, name, firstName, lastName }>` (по `users.name`, затем `id`). Пустая зона — `{ topics: [] }` без запроса.
- `GET /api/tests/topics/teacher-options`: `{ teachers: Array<{ id, name, firstName, lastName }> }` из `zoneOwnerCandidates()`; без `canManageCatalog` — 403 `{ error: 'Forbidden' }`.
- `PUT /api/tests/topics/:id/teachers` тело `{ teacherIds: string[] }` (uuid, уникальные, не больше 50): 403 без `canManageCatalog`; 400 `{ error: 'Bad request', details }` при неверном теле; 404 при отсутствии раздела; 400 `{ error: 'Учитель не найден или не активен' }`, если добавляемый id не проходит `isZoneOwnerCandidate`; 200 `{ teachers: Array<{ id, name, firstName, lastName }> }`. Чтение текущего набора, проверка и `setTopicTeachers(tx, { assignedBy: запрашивающий })` — в одной транзакции.
- `POST /api/tests/topics`, `PATCH` и `DELETE /api/tests/topics/:id`: первой проверкой `canManageCatalog` → 403 `{ error: 'Forbidden' }`; `requirePerm('tests', 'write')` у POST снят.
- `GET /api/tests`: прежняя форма `{ tests }`, условие `inArray(tests.topicId, scope.topicIds)` вместе с `topicId` из запроса; пустая зона — `{ tests: [] }`.
- `DELETE /api/tests/:id` без `zone.all`: 409 `{ error: 'У теста есть попытки учеников. Снимите публикацию или обратитесь к администратору' }`. Считаются попытки, у автора которых нет роли из `STAFF_ROLE_KEYS` (`not exists` по `user_roles`, `LIMIT 1`).
- `GET /api/tests/:id/export?withAnswers=true`: ответы только при `canWriteTest`; `GET /api/tests/topics/:slug/export?withAnswers=true`: только при `canWriteTopic` раздела. Иначе 200 и архив без `answer_keys.json`. Фильтр ссылок `isServableImageKey` не менялся.
