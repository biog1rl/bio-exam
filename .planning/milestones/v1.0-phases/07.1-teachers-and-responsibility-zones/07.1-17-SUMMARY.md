# Phase 07.1 Plan 17: карточка ученика у учителя и назначения по canUnassign Summary

Учитель на `/profile/<login>` своего ученика видит бейджи всех его групп, карточку «Контакты» (дата рождения dd.MM.yyyy, Telegram, `tel:`, `mailto:` с `break-all`, иначе «—», всё пусто — «Контакты не указаны») и карточку «Сеансы и вход» с кнопками «Снять ограничение входа» и «Завершить все сеансы»: подтверждения, тосты и 403 — тексты Phase 4 из `session-actions.ts`. Кнопка `Pencil` (`aria-label="Изменить профиль"`) и `EditUserDialog` есть только при `users.edit`. Назначение с `canUnassign: false` показывает «Назначил администратор» вместо удаления; 403 на назначение и снятие даёт «Недостаточно прав для этого действия. Обратитесь к администратору.». В `StudentAccessPanel` строка без `canUnassign` идёт без `Trash2` и с подписью «Не из ваших групп».
