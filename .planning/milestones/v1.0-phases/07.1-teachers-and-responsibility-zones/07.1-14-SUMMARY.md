## Решения исполнителя (автономно)

1. **Строка учителей в `TopicHero` для одного учителя** — «Учитель: {имя}» (как в навигации), для нескольких — «Учителя: {имя}, {имя}» по UI-SPEC.
2. **«Сохранить» в шапке редактора** (`TestEditorHeader.tsx`) не выключается: файл вне `files_modified`, сверка дала бы exit 1. Без тем её нажатие даёт прежний тост «Выберите тему» из `getBaseValidationError`, тест не создаётся. Выключена кнопка в `TestSettingsPanel`.
3. **Список учителей** запрашивается `apiFetch` при каждом открытии диалога (без SWR), чтобы после 400 «учитель деактивирован» следующий диалог показал свежий список. Ошибка запроса → пустой список с текстом `CommandEmpty`.
4. **Фильтр в `Command`** — свой `filter` по `keywords` (имя учителя), `value` пункта — id: стандартный нечёткий фильтр cmdk 1.1.1 ловил бы латинские запросы по шестнадцатеричным символам uuid. Фильтрация остаётся клиентской, `shouldFilter` не отключён.
5. **Чипы выбранных** собираются из `editingTopic.teachers` и списка кандидатов: закреплённый учитель, которого нет среди активных, остаётся видимым чипом и не теряется при сохранении.
6. **Загрузка прав.** Пока `useAuth().loading`, страница темы показывает скелет, а пустое состояние учителя на `/admin/tests` не выбирается: администратор без тем не увидит текст учителя на первом кадре.
7. **Диалог темы** получил `max-h-dvh overflow-y-auto` у `DialogContent` (UI-SPEC «Ширина 375px»: длинное содержимое диалога прокручивается внутри).
8. **Строка 409 без текста** (`error` пустой или не строка) даёт общий текст «Не удалось удалить тест. Попробуйте ещё раз.».
