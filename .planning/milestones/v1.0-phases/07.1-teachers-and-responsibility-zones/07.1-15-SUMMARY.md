# Phase 07.1 Plan 15: Раздел «Пользователи» учителя и приглашение ученика Summary

Учитель открывает «Пользователи» и видит только учеников своих групп (список фильтрует сервер), под заголовком подпись «Ученики ваших групп. Профиль меняет администратор.». Кнопка «Пригласить ученика» открывает диалог без поля «Роль» с обязательной «Группой» из `/api/groups`. Если группа одна, она выбрана сразу. Запрос уходит без `roleKey`, с `groupId`. Администратор приглашает с ролью из `useRoleTraits` (по умолчанию «Ученик») и необязательной группой с суффиксом владельца. Ошибки показываются по коду ответа, английские тексты сервера в интерфейс не попадают. В колонке «Группа» видны все группы ученика. Права в web определяют только то, что показывать, решает сервер.

## Решения исполнителя (автономно)

1. **Роль по умолчанию без признаков.** Если `/api/rbac/roles` не загрузился (признаки `null`), роль не выбирается, поле «Роль» показывает плейсхолдер «Выберите роль», «Создать приглашение» выключена до выбора. Первая роль списка (`Администратор`) по умолчанию — опасный выбор, ключ роли сравнивать нельзя. Пока список грузится, роль тоже не выбрана; после загрузки выбирается роль с `groupMember: true`. Совет проверяющего был взять первую роль; выбран более консервативный вариант.
2. **409 без `error` в теле** → общий текст «Не удалось создать приглашение. Попробуйте ещё раз.».
3. **«Учитель без групп»** показывается только после успешной загрузки `/api/groups`; во время загрузки видна форма с пустым выбором группы и выключенной кнопкой.
4. **Формы монтируются при открытии диалога.** После закрытия поля, выбранная группа и ссылка сбрасываются (раньше состояние жило между открытиями).
5. **Кнопка приглашения и диалог на странице — только при G-INV.** Раньше кнопка была у всех, кто открыл раздел.
6. **«Без группы»** в `Select` — служебное значение `__none__`, в запрос не попадает.
7. **Пустой текст учителя** считается по строкам, пришедшим в `UsersTable` (после фильтра групп): пропсы таблицы менять нельзя, о фильтре она не знает.
8. **`Select` роли и группы всегда управляемые:** без выбора значение `''` (показывается плейсхолдер), чтобы Radix не переключался из неуправляемого режима в управляемый при загрузке данных. После правки повторены web test (966 passed), typecheck (exit 0) и `oxfmt --check .`; `yarn verify` и `yarn e2e` выше прогонялись до этой правки.
9. **`DialogContent` приглашения** получил `max-h-dvh overflow-y-auto` (UI-SPEC «Ширина 375px»: длинное содержимое прокручивается внутри, как у `EditUserDialog`).
