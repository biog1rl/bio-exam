## Метод

- Поиск: `searchDatabase` с доступом, собранным так же, как в `routes/search.ts` (`requestAccess`, `testScope`, `groupScope`, `userScope`), для администратора и учителя. Запросы `клетка`, `митохондрия`, `фотосинтез`, `scope=all`, `limit=10`, по 50 прогонов на запрос (150 вызовов на доступ). Первые 3 вызова на доступ — прогрев, в статистику не входят. Счётчик — обёртка `pgPool.query`: число вызовов и максимум одновременных. p50 и p95 — ближайший ранг.
- Промпты: задержка чтения 20 мс на каждое `read` in-memory адаптера. Прохождение — `GET /api/tests/public/tests/:id` крупнейшего теста через HTTP с cookie ученика; администратор — `readAdminTest({ testId })` того же теста. 5 прогонов после 1 прогрева, время — медиана.
- ZIP: `buildTopicArchive` крупнейшей темы, `withAnswers: true`, `scope: { all: true }`, лимит выше размера архива. Задержка чтения 0 мс. 5 прогонов после 1 прогрева. Перед каждым прогоном — сборка мусора и пауза; пиковый буфер — максимум `process.memoryUsage().arrayBuffers` над исходным (опрос каждые 5 мс и в конце сборки). Счётчик приёмника «до» — размер буфера архива: приёмник держит архив целиком.
- Редактор: `next build` пишет `app/web/.next/diagnostics/route-bundle-stats.json`; `scripts/editor-bundle.mjs --report` суммирует файлы `firstLoadChunkPaths` маршрутов редактора (сырой размер и сумма `gzipSync` по чанкам) и ищет в них маркер данных `emoji-list` — строку `grinning face with big eyes` из `app/web/components/editor/utils/emoji-list.ts`.

## PERF-02: потолок одновременных чтений при задержке 120 мс

Потолок `PROMPT_READ_CONCURRENCY` (`app/server/src/services/question-content/bounded.ts`) выбран замером. Метрика — прохождение крупнейшего теста учеником (`GET /api/tests/public/tests/:id`, `bench-1-01`, 123 вопроса, 123 чтения) при задержке 120 мс на каждое чтение, медиана 5 прогонов после 1 прогрева. «До» — неограниченный `Promise.all` по вопросам. Правило: медиана «после» не больше 1,2 × медианы «до» (161,72 мс); потолок поднимается по ряду 6, 8, 12, 16, 24, 32, 48, 64, далее удвоение, не выше числа вопросов крупнейшего теста; выбирается первое значение, где правило выполнено. Сырые данные: `bench/prompts-120-before.json`, `bench/prompts-120-after-<потолок>.json`, сводка `bench/perf02-ceiling.json`.

| Потолок | Прохождение, медиана, мс | Максимум одновременных чтений | Чтение администратора, медиана, мс | Правило |
|---|---|---|---|---|
| до (без потолка) | 134,77 | 123 | 4 033,31 (партии по 5) | — |
| 6 | 2 572,10 | 6 | 3 418,21 | нет |
| 8 | 1 964,19 | 8 | 2 568,29 | нет |
| 12 | 1 353,03 | 12 | 1 712,46 | нет |
| 16 | 991,28 | 16 | 1 349,94 | нет |
| 24 | 747,43 | 24 | 862,83 | нет |
| 32 | 503,21 | 32 | 737,56 | нет |
| 48 | 379,52 | 48 | 495,93 | нет |
| 64 | 260,09 | 64 | 374,64 | нет |
| 123 | 131,70 | 123 | 251,89 | да |

Выбрано: `PROMPT_READ_CONCURRENCY = 123`. Любой потолок меньше 123 даёт не меньше двух раундов чтения по 120 мс на этот тест. Тесты крупнее 123 вопросов читаются окном по 123. Discretion D-21 (6–8) заменён замером по решению оркестратора.

При задержке 20 мс (основная таблица, 08-28) с этим потолком у прохождения и у чтения администратора максимум одновременных чтений — 123.

Команды повтора (из корня репозитория, около 30 с каждая). «До» снимается на коде до правки `public.ts`:

```bash
node scripts/with-test-db.mjs -- yarn workspace @bio-exam/server tsx src/scripts/bench/run.ts --only prompts --read-delay 120 --runs 5 --out .planning/phases/08-client-requests-runtime-and-decomposition/bench/prompts-120-before.json
```

«После» при текущем значении `PROMPT_READ_CONCURRENCY`:

```bash
node scripts/with-test-db.mjs -- yarn workspace @bio-exam/server tsx src/scripts/bench/run.ts --only prompts --read-delay 120 --runs 5 --out .planning/phases/08-client-requests-runtime-and-decomposition/bench/prompts-120-after-123.json
```

Флаги `--only prompts`, `--read-delay <мс>` (по умолчанию 20), `--runs <n>` (по умолчанию 5) не меняют вывод без флагов. С `--only prompts` в отчёте есть `only: "prompts"` и раздел `prompts` с фактическими `readDelayMs` и `runs`; разделов `search` и `zip` нет.
