# Phase 8 — UI Design Contract

> Узкий контракт («Только затронутое», подтверждено пользователем 2026-10-04) на поверхности web, которые фаза 8 меняет в видимом тексте и поведении: блок ошибки загрузки с кнопкой «Повторить» на экранах, переходящих на типизированный слой запросов (HTTP-01, HTTP-02, D-09); тексты отказов модуля запросов (D-02); серверные страницы на одном пути в Express и новая страница ошибки (HTTP-04, D-13); открытие пользователя вне первых 100 (D7, HTTP-03, D-11, D-12); ошибка глобального поиска; тосты экспорта ZIP при потоковой отдаче (PERF-04, D-25, D-26); видимое поведение редактора без `document` на сервере и с ленивыми группами плагинов (RT-01, RT-02, PERF-03); reduced-motion на затронутых элементах (RT-03, D-18).
>
> В `08-CONTEXT.md` (Discretion) записано «UI-SPEC не нужен». Оркестратор это решение отменил: при переносе на код фазы 07.1 нашлись видимые расхождения, которых CONTEXT не учитывает (английская страница ошибки, английские тексты сервера в причинах, 403 на страницах 07.1, четвёртый вызывающий `absoluteUrl`). Исходное состояние web — ветка `gsd/phase-07.1` (коммит `1d800af`): это `dev` вместе с фазами 6 и 7.1, фаза 7.1 вливается раньше фазы 8. Где CONTEXT расходится с этим кодом, контракт следует коду 07.1 и говорит об этом явно.
>
> Решения, подтверждённые пользователем, обязательны: D7 — открытие по `/profile/<login>`, «не найдено» и для отсутствующего, и для чужого пользователя (п. 3); строка ошибки и «Повторить» на экранах списков, истёкший сеанс ведёт на вход (п. 4); кнопка «Повторить» скрыта при 403 и 404 и показана при остальных ошибках (2026-10-05); лимит ZIP задаёт настройка сервера (п. 1); обрыв посреди потока даёт тост «Не удалось скачать архив…» (п. 2); reduced-motion только на элементах, которые меняет фаза (п. 5). Решения оркестратора по замечаниям проверки помечены «принято оркестратором». Остальное выбрано по рекомендованному варианту и помечено **[авто]**. Фаза не вводит новых компонентов `components/ui`, цветов, токенов и npm-пакетов.

## Color

Палитра не добавляется. Роли — из CSS-переменных `app/web/styles/globals.css` через существующие классы.

| Role | Value (существующие классы и переменные) | Usage |
|------|------------------------------------------|-------|
| Dominant (60%) | `bg-background`, фон рабочей области `bg-[#fbfaf7]` | не меняется |
| Secondary (30%) | `bg-card/90`, `border-border/80` | рамка страниц ошибки (как `AccessDeniedState`) |
| Accent (10%) | `bg-primary text-primary-foreground` (вариант `default` у `Button`) | новых мест нет |
| Destructive | `text-destructive`, `border-destructive/50` | только перечисленные ниже элементы |
| Muted text | `text-muted-foreground` | киккер, текст и код страниц ошибки; существующие пустые состояния |

Accent: фаза не добавляет ни одного элемента с акцентом. `Повторить`, `На главную` — `variant="outline"`. Существующие акцентные кнопки (`Сохранить`, `Новый тест`, `Создать группу` и т. п.) не меняются.

Destructive зарезервирован только для:
1. `Alert variant="destructive"` блока ошибки загрузки (рамка, заголовок, причина, пиктограмма `CircleAlert`);
2. пиктограммы `CircleAlert` обеих страниц ошибки, `(protected)/error.tsx` и `app/error.tsx` (`text-destructive`, как `AlertCircle` в существующем `TestsPageError`);
3. строк ошибок вспомогательных данных (`text-xs text-destructive`, Поверхность 1);
4. тостов ошибок (`toast.error`, цвет даёт `richColors`).

Кнопка `Повторить` внутри красного `Alert` получает `text-foreground`: у варианта `outline` нет своего цвета текста, иначе подпись унаследует красный и спутается с ошибкой. Цвет нигде не единственный носитель смысла: у блока есть заголовок «Не удалось…», у страницы — заголовок и текст.

## Поверхность 1. Блок ошибки загрузки и кнопка «Повторить» (HTTP-02, D-09, подтверждено пользователем п. 4)

Один прикладной компонент на все экраны, которые фаза переводит на типизированный слой запросов. Он заменяет ответ с ошибкой, который сейчас разбирается как данные и даёт пустой список, «зависшую» загрузку или голую строку `<p role="alert">`.

**Фокус:** заголовок «Не удалось загрузить …» и кнопка `Повторить` рядом с причиной.

### Разметка

```tsx
<Alert variant="destructive" className="rounded-3xl">
	<CircleAlert className="size-4" aria-hidden="true" />
	<AlertTitle>{title}</AlertTitle>
	<AlertDescription>
		<p>{reason}</p>
		{canRetry ? (
			<Button
				variant="outline"
				size="sm"
				className="mt-2 h-11 w-full rounded-full text-foreground mob:w-auto tab:h-8"
				onClick={onRetry}
				aria-disabled={retrying}
				aria-busy={retrying}
			>
				{retrying ? (
					<Loader2 className="size-4 animate-spin" aria-hidden="true" />
				) : (
					<RotateCw className="size-4" aria-hidden="true" />
				)}
				Повторить
			</Button>
		) : null}
	</AlertDescription>
</Alert>
```

Скругление `rounded-3xl` — как у пустых состояний (`rounded-3xl bg-secondary/70`) в тех же списках **[авто]**.

### Содержимое

| Часть | Правило |
|-------|---------|
| `title` | существующий текст ошибки экрана, если он есть (таблица экранов ниже); иначе `Не удалось загрузить данные` (D-09). Хвосты вроде «Обновите страницу.» убираются: их заменяет кнопка |
| `reason` | текст отказа модуля запросов (Поверхность 2) |
| `Повторить` | скрыта при `http` 403 и 404: повтор не изменит ответ. Показывается при всех остальных отказах блока: `network`, `malformed`, `http` с кодом ≥ 500 и прочие `http` 4xx (например 400, 409, 413) — подтверждено пользователем 2026-10-05. Правило отличается от строки автосохранения фазы 6 и действует только для блока ошибки загрузки |
| `auth` | блок не показывается: `apiFetch` уже повёл на вход. Экран остаётся в текущем виде (обычно скелетон загрузки) до перехода **[авто]** |
| `aborted` | блок не показывается, состояние экрана не меняется |

### Поведение `Повторить`

- Нажатие вызывает `mutate()` ключа SWR этого блока (или повторный запуск загрузки там, где SWR нет: правила баллов, пункты меню, медиатека).
- Пока идёт повтор: пиктограмма `RotateCw` меняется на `Loader2`, кнопка получает `aria-busy="true"` и `aria-disabled="true"`, повторные нажатия игнорируются. Атрибут `disabled` не ставится: выключенная кнопка теряет фокус **[авто]**.
- Повтор снова не удался: блок остаётся, причина обновляется, кнопка снова активна, фокус остаётся на ней.
- Повтор удался: блок заменяется данными экрана. Фокус, если он был внутри блока, переходит на заголовок области, которую блок занимал (`h1` экрана или заголовок карточки с `tabIndex={-1}`, таблица экранов ниже); где заголовка нет — остаётся поведение браузера (backstop) **[авто]**.
- Состояния загрузки и пустого списка не меняются (D-09). Ошибка загрузки больше никогда не показывается текстом пустого состояния.

## Поверхность 2. Тексты отказов модуля запросов (D-02)

Модуль собирает текст для показа по виду отказа. Экраны выводят его как `reason` в блоке ошибки (Поверхность 1) или в `toast.error` действия. Тексты, которые 07.1 уже задала вызывающим (приглашение, сохранение группы, удаление теста, «Сеансы и вход», назначения), остаются у вызывающих и имеют приоритет.

| Вид отказа | Текст |
|------------|-------|
| `network` | `Нет связи с сервером. Проверьте подключение и повторите попытку.` |
| `malformed` | `Сервер вернул некорректный ответ. Повторите попытку позже.` |
| `http` 403, текста нет или он не на русском (например `Forbidden`) | `Недостаточно прав для этого действия. Обратитесь к администратору.` |
| `http` 4xx, поле `error` на русском | текст сервера без изменений (например, `Пользователь не найден`, `Архив слишком большой для выгрузки, экспортируйте тесты по отдельности`, `Логин уже используется`) |
| `http` 4xx, кроме 403, текста нет или он не на русском | запасной текст вызывающего, если он есть сейчас (`Ошибка экспорта`, `Ошибка сохранения` и т. п.); иначе `Запрос отклонён (код {N}).` (принято оркестратором) |
| `http` ≥ 500 | текст сервера не показывается; запасной текст вызывающего, иначе `Ошибка сервера (код {N}).` (принято оркестратором) |
| `auth` | текста нет, тоста нет: переход на вход |
| `aborted` | ничего |

Отличия от D-02:
1. **Английский текст сервера не показывается** (принято оркестратором). Production-`errorHandler` отвечает на 500 `Internal Server Error`; маршруты отвечают `Bad request`, `User not found`, `Test not found`, `Failed to fetch sidebar items` и ещё около 30 английскими строками. Текст считается русским, если в нём есть хотя бы одна кириллическая буква. Без кириллицы показывается запасной текст вызывающего, иначе `Запрос отклонён (код {N}).` для 4xx и `Ошибка сервера (код {N}).` для 5xx. Так уже решено в 07.1 (Поверхность 4: «английские строки сервера не показываются»).
2. **403 — полный текст 07.1** `Недостаточно прав для этого действия. Обратитесь к администратору.` вместо короткого из D-02: одна фраза для одного случая во всём приложении **[авто]**.
3. **Точка в конце** у многословных текстов (`network`, `malformed`, оба текста с кодом) — как у текстов ошибок 07.1. Тексты сервера не правятся: точку им не добавляют **[авто]**.

Помощник `readApiError` (07-14) входит в модуль и следует этой таблице.

## Поверхность 3. Серверные страницы и страница ошибки (HTTP-04, D-13, D-14)

Все серверные страницы ходят в Express одним примитивом модуля веб-сессии (`API_ORIGIN`, cookie запроса, тело читается на каждой ветке). `absoluteUrl` удаляется вместе с доверием к `x-forwarded-host`.

**Фокус:** заголовок `Не удалось загрузить страницу` и кнопка `Повторить`.

### Исходы по страницам

**Отступление от D-13** (принято оркестратором). D-13 даёт «403 и 404 → `notFound()`» для всех серверных страниц. Так требует фаза 07.1: на 403 она уже показывает `AccessDeniedState` (07.1, Поверхность 9; e2e учителя на это опирается). Поэтому:
- 403 на попытке (`/admin/attempts/<id>`) → `AccessDeniedState` `Нет доступа к попытке`, как в 07.1;
- 403 в layout теста (`admin/tests/[topicSlug]/[testSlug]/layout.tsx`) → `AccessDeniedState` `Нет доступа к тесту`, как в 07.1;
- 403 на `/admin/users/<id>` → `notFound()`, как в D-12.

Примитив возвращает исход вида `ObjectAccess` (`ok` / `denied` / `missing` / `error`, `lib/session/object-access.ts`), а каждая страница решает, что показать.

| Страница | 401 | 403 | 404 | 5xx, сеть, некорректный JSON | Сейчас при ошибке |
|----------|-----|-----|-----|------------------------------|-------------------|
| `/admin/attempts` (`admin/attempts/page.tsx`) | `redirect(buildLoginRedirect('/admin/attempts'))` | `notFound()` (раздел уже прошёл гейт `attempts`, 403 здесь не ожидается) | `notFound()` | исключение → страница ошибки | пустой список «Попыток пока нет» |
| `/admin/attempts/<id>` (`admin/attempts/[id]/page.tsx`) | вход с возвратом на путь | `AccessDeniedState` `Нет доступа к попытке` (07.1, без изменений) | `notFound()` | исключение → страница ошибки | 404 на любую ошибку |
| `/admin/users/<id>` (`admin/users/[id]/page.tsx`) | вход с возвратом | `notFound()` (D-12) | `notFound()` | исключение → страница ошибки | 404 |
| Тест в редакторе (`admin/tests/[topicSlug]/[testSlug]/layout.tsx`) — четвёртый вызывающий `absoluteUrl`, в CONTEXT не назван | вход с возвратом | `AccessDeniedState` `Нет доступа к тесту` (07.1, без изменений) | дочерняя страница рисуется, как сейчас; её клиентский блок показывает ошибку | дочерняя страница рисуется, как сейчас **[авто]**: layout — проверка доступа, а не загрузка данных; клиентская страница сама покажет блок ошибки с `Повторить` | дочерняя страница |

Страница 404 (`app/not-found.tsx`) не меняется.

### Страницы ошибки `app/(internal)/(protected)/error.tsx` **[авто]** и `app/error.tsx` (принято оркестратором)

Сейчас исключение уходит в корневой `app/error.tsx` — английскую заготовку `Something went wrong!` / `Try again` без стилей. Фаза 8 делает её реальной поверхностью (D-13 направляет туда ошибки страниц попыток), поэтому вводится граница ошибок сегмента `(protected)`: она ловит ошибки всех защищённых страниц, сайдбар и шапка остаются на месте.

Корневой `app/error.tsx` переводится на ту же разметку и те же тексты: заголовок, текст, код ошибки, `Повторить` через `retry()`, `На главную`. Он ловит ошибки страниц вне `(protected)`: вход, приглашение, корневая страница. Ошибки самого корневого layout (`AppLayout`) сюда не попадают: их ловит `global-error.tsx`, которого в проекте нет, фаза его не добавляет. Обе страницы не добавляют собственной обёртки: это та же `section`, она рисуется в слоте содержимого корневого layout (на `/login` и `/invite` сайдбар и шапка ведут себя так же, как на самих этих страницах). После фазы английских строк в страницах ошибки не остаётся.

```tsx
'use client'

<section className="rounded-4xl border border-border/80 bg-card/90 p-unit-mob shadow-sm tab-sm:p-unit">
	<CircleAlert className="size-7 text-destructive" aria-hidden="true" />
	<p className="mt-4 font-mono text-xs tracking-[0.22em] text-muted-foreground uppercase">ошибка</p>
	<h1 ref={headingRef} tabIndex={-1} className="mt-2 font-serif text-3xl leading-tight break-words outline-none">
		Не удалось загрузить страницу
	</h1>
	<p className="mt-4 max-w-2xl text-sm leading-6 text-muted-foreground">
		Сервер не ответил или вернул ошибку. Повторите попытку. Если ошибка повторяется, обратитесь к администратору.
	</p>
	{error.digest ? (
		<p className="mt-2 text-xs text-muted-foreground">
			Код ошибки: <span className="font-mono break-all">{error.digest}</span>
		</p>
	) : null}
	<div className="mt-8 flex flex-wrap gap-2">
		<Button variant="outline" className="w-full rounded-full bg-card mob:w-auto" onClick={() => retry()}>
			<RotateCw className="size-4" aria-hidden="true" />
			Повторить
		</Button>
		<Button variant="outline" asChild className="w-full rounded-full bg-card mob:w-auto">
			<Link href="/dashboard">
				<ArrowLeft className="size-4" aria-hidden="true" />
				На главную
			</Link>
		</Button>
	</div>
</section>
```

| Элемент | Правило |
|---------|---------|
| Рамка, отступы, гарнитуры | как `AccessDeniedState` (07.1): одна визуальная семья «страница не открылась». Киккер 12px (`text-xs`) вместо 11px у `AccessDeniedState`, чтобы не вводить четвёртый размер; `AccessDeniedState` не меняется |
| Обе страницы | `(protected)/error.tsx` и `app/error.tsx` — одинаковая разметка, тексты и поведение |
| `error.message` | не выводится: в production он обобщён, в разработке может нести внутренний текст |
| `Код ошибки` | только если есть `error.digest`; по нему ищется запись в логах сервера |
| `Повторить` | `retry()` из Next 16 — перезапрашивает и перерисовывает сегмент; при успехе страница заменяет блок |
| `На главную` | `/dashboard` (корень `/` туда же перенаправляет) |
| Акцент | нет: обе кнопки `outline` |

### Ширина 375px

Рамка `p-unit-mob`, заголовок `text-3xl` переносится по словам; текст во всю ширину; код ошибки переносится (`break-all`); `Повторить` и `На главную` друг под другом во всю ширину.

## Поверхность 8. Reduced-motion на затронутых элементах (RT-03, D-18, подтверждено пользователем п. 5)

Правило: элемент «затронут», если фаза 8 меняет его разметку или обработчик, либо это анимированный элемент редактора в файлах, которые меняют RT-01, RT-02 и PERF-03, либо его называет подтверждённая находка React Doctor. Глобального CSS-правила нет. Индикаторы загрузки-пиктограммы (`animate-spin`) крутятся и дальше: это сигнал работы. Переходы только цвета (`transition-colors`) остаются: это не движение **[авто]**.

| Файл, элемент | Сейчас | При `prefers-reduced-motion: reduce` |
|---------------|--------|---------------------------------------|
| `MediaLibrary.tsx`, миниатюра (`img`) | `transition-transform group-hover:scale-105` | `motion-reduce:transition-none motion-reduce:group-hover:scale-100`: без увеличения |
| `MediaLibrary.tsx`, кнопка удаления на миниатюре | `opacity-0 transition-all group-hover:opacity-100` | `motion-reduce:transition-none`: появляется сразу. Независимо от настройки **[авто]**: `focus-visible:opacity-100` (кнопка видна при фокусе с клавиатуры) и `aria-label="Удалить {filename}"` вместо одного `title` |
| `SearchDialog.tsx`, кнопки вкладок | `transition-all active:scale-[0.99]` | `motion-reduce:transition-none motion-reduce:active:scale-100` |
| `SearchDialog.tsx`, смена вкладки (`motion.div`: затухание 0,18 с и размытие 8px через `blur`) | анимация | без размытия и с `duration: 0`; проверка — помощник `prefersReducedMotion()` из `lib/utils` (D-18) в эффекте смены вкладки и при расчёте `transition` |
| `SearchDialog.tsx`, `Ищем…` и `…` у вкладки «Все» | `animate-pulse` | `motion-reduce:animate-none`: смысл несёт текст, мигание — украшение **[авто]** |
| `floating-text-format-plugin.tsx`, плавающая панель форматирования | `transition-opacity duration-300` | `motion-reduce:transition-none` |
| `LoadErrorAlert`, `Loader2` во время повтора | `animate-spin` | крутится (индикатор работы) |

Не затронуты и не меняются: `interactiveClass` (`transition-all duration-200`) в `TestsClient` (фаза меняет там только загрузку и экспорт), анимации открытия `Dialog`, `Popover`, `Tooltip`, `DropdownMenu` из `components/ui` (общие компоненты, их правка равна глобальному правилу, отклонённому п. 5), `scrollIntoView({ behavior: 'smooth' })` в `attempt-review-utils.ts` (файл фаза не меняет), страница 404. Итоговый список — в SUMMARY плана RT-03 (D-18); таблица выше — стартовый список, а не закрытый.

Проверка: на macOS «Уменьшить движение» (или эмуляция `prefers-reduced-motion` в DevTools) — у элементов таблицы нет движения, спиннеры крутятся.
