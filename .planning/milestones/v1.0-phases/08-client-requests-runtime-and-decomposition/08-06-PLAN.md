<objective>
D7 в Express (HTTP-03, D-11): поиск пользователя по id и по логину на общем сериализаторе строки списка.

Purpose: web (08-11) открывает любого пользователя, в том числе за пределами первых 100, а не ищет его в списке `GET /api/users`.
Tracer — `GET /api/users/:id` для 150-го пользователя через `app.ts` на `test_*` → `{ user }` совпадает со строкой списка → расширение до `by-login`, отказов, матрицы учителя, охранного теста и снимка инвентаря.
Output: `user-rows.ts`, два маршрута, тесты, строки матрицы и охранного теста, обновлённый снимок.

Решение планировщика: D-11 называет `requirePerm('users','read')` плюс `canReadUser`; охранный тест 07.1 запрещает `requirePerm(` у объектных маршрутов, поэтому маршруты вносятся в его инвентарь видом «грубый гейт и вызовы шва» (как `POST /api/auth/invites`). Несуществующий пользователь: 404 администратору, 403 учителю (решение 07.1 «seam-first», дописано в CONTEXT D-11: «404 только при `hasGlobalZone`, учителю 403»; web показывает «Пользователь не найден» в обоих случаях, 08-UI-SPEC Поверхность 4).

Решения по ревью: scope сериализатора берётся из `userScope(req)` целиком, иначе путь `{ all: true }` откатил бы правку eae17fe (учитель видел бы `createdByName` с логином и группы других учителей); поиск по логину — точное совпадение, затем `lower(users.login)` при единственной строке (D-11 «как при входе» уточнено решением оркестратора R7: логин из профиля хранится без нормализации). Сколько логинов на проде не нормализовано, пользователь проверяет read-only запросом из 08-28.

Файлы `routes/users/index.ts`, `teacher-zone-users.matrix.test.ts` и `teacher-zone-guards.test.mjs` правились ревью 07.1: ориентироваться на имена символов, не на номера строк.

Правила плана: комментарии в код не писать нигде; тесты с БД только через `node scripts/with-test-db.mjs -- …`, `DATABASE_URL` не использовать; миграций нет; форма ответа `GET /api/users` не меняется; план не коммитит. Начало — команда снимка из 08-01 и `codegraph impact`; конец — `codegraph affected`, `yarn verify`, команда сверки.
</objective>
