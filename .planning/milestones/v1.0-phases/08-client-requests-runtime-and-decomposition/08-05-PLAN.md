Создаётся (используют 08-11 и 08-23):
```typescript
export type ServerOutcome<T> =
  | { kind: 'ok'; data: T }
  | { kind: 'unauthorized' }
  | { kind: 'denied' }
  | { kind: 'missing' }
  | { kind: 'error'; status?: number; cause?: unknown }
export function serverRequest<T>(path: `/api/${string}`, options: { parse: (body: unknown) => T }): Promise<ServerOutcome<T>>
export function requireServerData<T>(outcome: ServerOutcome<T>, currentPath: string): T
```
`requireServerData`: unauthorized → `redirect(buildLoginRedirect(currentPath))`; denied и missing → `notFound()`; error → `throw new Error(...)` (без тела ответа в сообщении); ok → `data`.
