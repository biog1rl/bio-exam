## Deviations from Plan

### Решения исполнителя (автономно)

**1. Отложенные шаги переписаны под собственный сервер.** Список Task 3 был составлен для Vercel + Supabase (preview server-проекта, env web-проекта Vercel, `maxDuration`). По решению пользователя от 2026-10-05 прод переехал на Beget. Профиль `~/.claude/servers/bio-exam.md`: переезд выполнен 2026-10-05 15:55, `master` выкатывается автоматически. Поэтому проверки D-27 и D-35 перенесены на собственный сервер после выкатки фазы 8. Пункты только для Vercel и Supabase оставлены в списке с пометкой «неактуально после переезда». Ключевые слова проверки плана (`preview`, `maxDuration`, `APP_ORIGIN`) в тексте есть.

**2. Порядок выкатки server → web и отката web → server.** На собственном сервере web и API идут из одного образа (`bio-exam-app:<sha>`): `deploy.sh` переключает их одним `up -d --wait api web` и откатывает оба через `.env.prev`. Риск R10, когда старый web или server остаётся с новым партнёром, сводится к окну пересоздания контейнеров. Правило отката записано так: оба сервиса только вместе, отдельно `api` не откатывать.

**3. Разбор времени поиска.** Разовый скрипт в scratchpad. Он не входит в репозиторий и в `bench/`.
