# Диалог «Добавить фото с телефона»

Дизайн-система, карточка `QrUploadDialog`. Заменяет поверхность 1 «Панель QR» из `13-UI-SPEC.md`: по кнопке открывается диалог, QR — `@lglab/react-qr-code` в цветах токенов вместо `qrcode.react` (решения владельца 2026-10-16). Остальное из `13-UI-SPEC.md` в силе: страница телефона, выдача и ротация ссылки, опрос, `uploadWindowView`.

## Кнопка

- В `PhotoBlock` раннера рядом с «Добавить фото»: `Button variant="outline" size="sm" className="rounded-full"`, иконка `Smartphone`, текст «С телефона», `aria-label="Добавить фото с телефона"`.
- Только при `usePointerKind() === 'fine'`. На `'coarse'` её нет: блок даёт «Сделать фото» и «Выбрать из галереи».

## Окно

- `Dialog` из `components/ui`: фон `bg-popover`, `max-w-md` (448px), `p-6`, до 768px `p-4`; до 768px ширина `calc(100% - 2rem)`. Оверлей общий.
- Порядок сверху вниз, зазор 16px:
  1. `DialogTitle` «Добавить фото с телефона» (`text-lg font-semibold`), под ним `DialogDescription` (`text-sm text-muted-foreground`).
  2. QR по центру, без рамки и плитки, фон кода = `card`, как у окна.
  3. По центру: счётчик (`Images` 16px, `text-sm font-medium tabular-nums`, `aria-live="polite" aria-atomic="true"`); под ним строка окна (`text-sm text-muted-foreground tabular-nums`; при `closing`/`last-minute` — `Clock3` и `font-medium text-foreground`, как `UploadWindowLine`).
  4. Ссылка: подпись `text-xs text-muted-foreground`; ряд из поля только для чтения (`Input readOnly`, `bg-card font-mono text-xs`, `truncate`, по фокусу выделяет всё) и кнопки `variant="outline" size="sm" rounded-full` с `Copy`; под рядом — строка о приватности (`text-xs text-muted-foreground`).
  5. `DialogFooter`: «Закрыть» (`variant="outline"`). Крестик в углу — ghost 32px «Закрыть».

## QR

`@lglab/react-qr-code`, компонент `ReactQRCode` (SVG, MIT, без зависимостей, `react` ^18 || ^19). Версия — 1.7.3 (2026-09-08). В 1.8.x добавлен только `frameSettings`, он не нужен, а 1.8.1 моложе двух недель. Имена пропов сверены по `dist/types/lib.d.ts` пакета.

```tsx
<ReactQRCode
  value={url}
  size={240}                     // до 500px: 224
  level="Q"
  marginSize={4}                 // тихая зона 4 модуля по спецификации
  background="#fffdf2"           // card
  dataModulesSettings={{ style: 'leaf', color: '#182610' }}               // foreground
  finderPatternOuterSettings={{ style: 'rounded-lg', color: '#4b6b38' }}  // primary
  finderPatternInnerSettings={{ style: 'circle', color: '#4b6b38' }}      // primary
  svgProps={{ 'aria-label': 'QR-код для загрузки фото с телефона' }}
/>
```

- `gradient`, `imageSettings` и `frameSettings` не задаются. Иконки в центре нет: ссылка с токеном длинная, код плотный, а фото крон малоконтрастно.
- Цвета — hex токенов `foreground`, `primary` и `card` (sRGB от OKLCH из `globals.css`). Контраст точек к фону 15,5:1, глазков — 5,9:1. Бирюзовые глазки из образца владельца не берём: `chart-3` даёт 2,7:1.
- Запасной вид, если на устройствах читается хуже: `dataModulesSettings.style: 'circle'` и `finderPatternOuterSettings.style: 'circle'`, остальное то же.
- `svgProps['aria-label']` обязателен: по умолчанию библиотека ставит английский `aria-label="QR Code"` при `role="img"`.
- jsQR читает вывод библиотеки (оба вида, 240 и 224px, ужатые до 120px); камеры iPhone и Android — при приёмке.

## Тексты

| Где | Текст |
|---|---|
| Заголовок | `Добавить фото с телефона` |
| Пояснение | `Наведите камеру телефона на QR-код и откройте ссылку. Фото сразу появятся в ответе к вопросу {n}.` |
| Счётчик | `{N} из {M} фото`, M — `maxPhotos` вопроса (1–10) |
| Лимит, под счётчиком | `Чтобы добавить другое фото, удалите одно из прикреплённых.` |
| Строка окна | `uploadWindowView`: `Фото можно добавить до {HH:mm} · осталось {N} мин`, `закроется через {N} мин`, `закроется меньше чем через минуту`; `uploadClosesAt === null` — строки нет |
| Подпись ссылки | `Ссылка для телефона` |
| Кнопка | `Скопировать` (`aria-label` `Скопировать ссылку`) → `Скопировано` с `Check` на 3 с; скрытый `aria-live` повторяет |
| Буфер недоступен | `Не удалось скопировать. Выделите ссылку и скопируйте её вручную.` (`text-xs text-destructive`, `role="status"`; сначала пробуется `execCommand('copy')`) |
| Приватность | `Ссылка работает только для этого вопроса, пока открыто время для фото. Не отправляйте её другим: по ней можно добавлять и удалять фото вашего ответа.` |
| Ссылка готовится | `Создаём ссылку…` |
| Не удалось создать | `LoadErrorAlert`: `Не удалось создать ссылку`, причина `loadErrorView`, `Повторить` (сеть, 5xx, 429, 401 при недоступном refresh) |
| Отказ 403 | тот же `LoadErrorAlert` без `Повторить`, причина `Недостаточно прав для этого действия. Обратитесь к администратору.` (`loadErrorView`) |
| Фото к вопросу выключили | `К ответу на этот вопрос нельзя прикрепить фото. QR-код не нужен.` (`ANSWER_PHOTO_FORBIDDEN_MESSAGE` и хвост) |
| Нет связи при опросе (2 неудачи подряд) | `Нет связи с сервером. Фото с телефона появятся, когда связь вернётся.` (`text-xs text-muted-foreground`, `role="status"`) |
| Окно закрыто | `Время для добавления фото закончилось в {HH:mm}. QR-код больше не работает.`; другой день — `… закончилось {d MMM} в {HH:mm}. …`; под счётчиком `Загруженные фото остались в ответе.` |
| Окна нет | `К этой попытке фото добавить нельзя. QR-код не нужен.` |
| Низ | `Закрыть` |

## Состояния

| Состояние | Вид |
|---|---|
| ссылка готовится | вместо QR `Skeleton` 240×240 `rounded-md`; `Loader2` и «Создаём ссылку…»; поле пустое, кнопка `disabled`; счётчик — текущее число из `PhotoBlock`; опрос не идёт |
| готово | QR, счётчик, строка окна, ссылка; опрос раз в 2,5 с, пока окно открыто |
| не удалось создать | `LoadErrorAlert` на месте QR и ссылки; счётчика и строки окна нет. 401 обрабатывает `apiFetch` (refresh, иначе уход на вход) — диалог его не рисует |
| окно закрыто, окна нет, фото выключили | QR и ссылки нет; по центру круг 48px `bg-muted` с `TimerOff` (окно) или `ImageOff` (фото выключили) 20px `text-muted-foreground`, текст, счётчик; опрос останавливается |
| ссылку погасили в другой вкладке | при каждом открытии диалог подтверждает ссылку запросом выдачи; до ответа — «ссылка готовится», QR из `sessionStorage` без подтверждения не показывается |
| лимит M из M | QR остаётся (с телефона можно удалить фото), под счётчиком строка лимита |
| фото пришло | счётчик меняется и объявляется; новая строка в `PhotoBlock` за окном появляется тем же опросом |

## Ширины

- 1280: окно 448px по центру, QR 240px.
- 375: окно во всю ширину минус 16px с каждой стороны, поля 16px, QR 224px, ссылка обрезается многоточием, кнопка «Скопировать» не переносится. Горизонтальной прокрутки нет.

## Фокус и клавиатура

- При открытии фокус на «Скопировать»; пока ссылка готовится или при ошибке — на «Закрыть» (`onOpenAutoFocus`).
- Tab по кругу внутри окна, Esc закрывает, фокус возвращается на «С телефона» (`use-return-focus`).
- Кольцо фокуса — общее 3px `ring`.
