# Загрузка фото после сдачи

Дизайн-система bio-exam, версия 13, карточка `PostSubmitPhotos`. Решение владельца 2026-10-17. После сдачи, пока открыто время для фото, раннер показывает список всех открытых вопросов с разрешёнными фото. Этот список заменяет блок фото одного текущего вопроса. Связанные контракты: `qr-dialog.md` (кнопка «С телефона»), `photo-viewer.md` (миниатюры). Тексты окна — `uploadWindowView` / `UploadWindowLine`, тексты строк фото и ошибок — как в `PhotoBlock` (`12-UI-SPEC.md`).

## Когда показывается

- После ручной сдачи — если хоть у одного вопроса с `allowPhotos` нет ни одного фото.
- После сдачи по таймеру — всегда, если в тесте есть вопросы с `allowPhotos`.
- Только пока окно открыто: `uploadWindowView(...).state` не `none` и не `closed`. В остальных случаях — сразу итоговое состояние (см. ниже).

## Место и раскладка

- В раннере под h1 теста, вместо карточки вопроса, навигации «Назад/Далее» и боковой панели. Ничего из раннера под экраном не остаётся.
- Одна `Panel`: `rounded-3xl border bg-card`, `p-5`, до 768px `p-4`, ширина `max-w-3xl` (768px); до 768px — во всю ширину.
- Шапка Panel, зазор 4px:
  - h2 «Добавьте фото к ответам» (`text-lg font-semibold`, `tabIndex={-1}`, фокус при показе);
  - строка окна `UploadWindowLine`;
  - `text-sm text-muted-foreground`: «Тест сдан. Добавьте фото решений, пока открыто время для фото.».
- Список `ul`, строки разделены `border-t`, поля строки `py-4`.
- Низ Panel: `border-t pt-4`, кнопка и подпись.

## Строка вопроса

1. Верхний ряд `flex justify-between items-start gap-3`:
   - слева «Вопрос {n}» (`text-sm font-medium`), рядом плашка «Нет фото», если фото 0 и ничего не грузится;
   - под ним начало текста вопроса: `mdxFallbackText`, `text-xs text-muted-foreground line-clamp-2`;
   - справа счётчик «{N} из {M}» (`text-sm text-muted-foreground tabular-nums shrink-0`, `aria-live="polite" aria-atomic="true"`), M — `maxPhotos` вопроса.
2. Миниатюры, если есть: `flex flex-wrap gap-3`.
   - Плитка — `button` 64×64, `rounded-md border bg-muted overflow-hidden`, `object-cover`, `aria-label` «Открыть фото {k} к вопросу {n}», открывает `PhotoViewer` с фото этого вопроса.
   - В углу у готового фото — кнопка удаления: `variant="outline"`, 24px видимых, `rounded-full`, `-top-2 -right-2`, `X` 14px, цель касания 44px (`after:absolute after:-inset-2.5`), `aria-label` «Удалить фото {k} к вопросу {n}». Удаление сразу, без подтверждения, как в `PhotoBlock`.
   - Загрузка: плитка `bg-muted`, `Loader2` 16px `text-muted-foreground`, скрытое «Загрузка…» (`role="status"`), без кнопки удаления.
   - Ошибка: плитка `bg-destructive-soft` с `CircleAlert` 16px `text-destructive`, без кнопки в углу; под плитками строка `role="alert"` `text-sm text-destructive` «Фото {k} не загружено: {причина}» (причины — тексты `PhotoBlock`) и кнопка «Повторить» (сбой) или «Убрать» (отказ), ghost sm `rounded-full`.
3. Кнопки, `flex gap-2`:
   - на компьютере (`usePointerKind() === 'fine'`): «Добавить фото» (`ImagePlus`) и «С телефона» (`Smartphone`, `aria-label` «Добавить фото с телефона к вопросу {n}») — `variant="outline" size="sm" rounded-full`; «С телефона» открывает QR-диалог для слота этого вопроса;
   - на телефоне: «Сделать фото» (`Camera`) и «Выбрать из галереи» (`Images`) — `variant="outline" rounded-full h-11`, до `mob` во всю ширину столбиком; «С телефона» нет.
4. Лимит M из M: кнопки `aria-disabled`, под ними `text-xs text-muted-foreground` «Чтобы добавить другое фото, удалите одно из прикреплённых.».

Плашка «Нет фото»: `rounded-full border border-warning-border bg-warning-soft px-2 py-0.5 text-xs font-medium text-warning`, иконка `CircleAlert` 14px.

## Порядок

- Сверху вопросы без фото, затем с фото; внутри групп — по номеру вопроса.
- Порядок считается один раз при показе экрана и дальше не меняется: строка не прыгает, когда в ней появляется фото, и не прыгает, когда фото удаляют.

## Низ и «Готово»

- Кнопка «Готово, фото загружены» — `default`, на компьютере своей ширины слева, до 768px `h-11 w-full`.
- Под кнопкой `text-xs text-muted-foreground`: «После нажатия окно загрузки закроется, и работа сразу попадёт к проверяющему.».
- Пока у любого вопроса идёт загрузка (`preparing`, `uploading`, `retrying`), кнопка `disabled`, а подпись меняется на «Дождитесь, пока загрузятся все фото.».
- Во время отправки — `Loader2` в кнопке, `aria-busy`.
- Ошибка отправки: `role="alert"` `text-sm text-destructive`, текст `failureMessage(outcome)` или «Не удалось завершить загрузку. Повторите попытку.».
- Отказ окна `UploadWindowRefusal` — то же, что успех: переход в итог (как в `SubmittedPhotos`).
- Подтверждение — `AlertDialog`, если у K вопросов фото 0. Без подтверждения отправка идёт сразу.
  - Заголовок: «Отправить работу без части фото?».
  - Текст: «Нет фото у {K} {вопроса/вопросов}: {номера через запятую и «и»}. Вопрос без текста и без фото получит 0 баллов. После отправки добавить фото будет нельзя.».
  - Склонение через `plural` (`@bio-exam/exam-core`): 1 вопроса, 2 вопросов, 5 вопросов.
  - Кнопки: «Вернуться» (`outline`), «Отправить» (`default`).
- Ноль получает только пустой ответ — без текста и без фото (решение 2026-10-06); вопрос с текстом проверяется по тексту. Поэтому в подтверждении нет «им поставят 0».

## Итоговое состояние

Panel той же ширины, `space-y-3`.

**После «Готово» или если экран не нужен.**
- Круг 48px `bg-success-soft` с `Send` 20px `text-success`.
- h2 «Работа отправлена на проверку», фокус на нём.
- `text-sm text-muted-foreground`: «Ответы и фото приняты. Учитель проверит работу, об итоге придёт уведомление.».
- Ряд: плашка «На проверке» (`StatusPill` small) и `text-xs text-muted-foreground` «предварительно {X} из {Y} баллов». Без автопроверяемых вопросов этой строки нет.
- Кнопки «К тесту» и «Ко всем тестам» — `outline sm rounded-full`.

**Окно закрылось по времени, пока экран открыт.**
- Тот же вид, круг `bg-muted` с `TimerOff`.
- Текст: «Время для фото закончилось в {HH:mm}. Загруженные фото и ответы приняты, об итоге придёт уведомление.»; другой день — «… закончилось {d MMM} в {HH:mm}. …».
- Незавершённые загрузки отменяются; строки с ними не показываются.

## Ширины

- 1280: Panel 768px слева под h1. В строке кнопки в ряд, миниатюры в ряд с переносом.
- 375: Panel во всю ширину, поля 16px. Кнопки 44px столбиком во всю ширину, «Готово» 44px во всю ширину. Начало текста вопроса — две строки. Строка окна переносится по `UploadWindowLine`. Горизонтальной прокрутки нет.

## Фокус, клавиатура, объявления

- При показе экрана фокус на h2.
- Tab по порядку: строки сверху вниз (миниатюры, удаление, кнопки), затем «Готово».
- После удаления фото фокус уходит на соседнюю миниатюру или на «Добавить фото» этого вопроса.
- Закрытие `PhotoViewer` и QR-диалога возвращает фокус на кнопку, которая их открыла.
- Каждый счётчик «{N} из {M}» объявляется сам; ошибки строк — `role="alert"`.
- После «Отправить» и при закрытии окна фокус переходит на h2 итога.

## Данные

- Вопросы попытки с `allowPhotos`, `maxPhotos`, номером и текстом.
- Признак, есть ли текст ответа (для подтверждения не нужен, текст фиксированный).
- Фото и очередь на вопрос (`useAnswerPhotos`).
- `uploadClosesAt` и смещение часов сервера.
- Предварительные баллы из `attemptResultView`.
- Команда `completeAnswerUploads` для всей попытки.

## Как проверить

- Сдать тест с двумя вопросами с фото, оба без фото: экран показан, оба с плашкой «Нет фото», порядок 4, 7.
- Добавить фото к первому — плашка пропала, порядок прежний.
- «Готово» → подтверждение «Нет фото у 1 вопроса: 7…» → «Отправить» → итог, фокус на h2.
- Таймерная сдача с фото у всех вопросов: экран всё равно показан.
- 375: нет горизонтальной прокрутки, все кнопки высотой 44px.
- Контраст плашки «Нет фото» (`warning` на `warning-soft`) ≥ 4,5:1.
