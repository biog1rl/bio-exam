Сдача по дедлайну и окно для фото

Зачем · цель фазы и решения пользователя Сервер сам закрывает попытку теста с лимитом времени в дедлайн плюс существующий грейс, не теряя сохранённый текст; окно дозагрузки фото после окончания времени задаётся автором теста и решается одной серверной функцией по времени базы… Если в черновике нет ни одного сохранённого ответа, попытка не создаётся: сессия закрывается как сейчас… Хотя бы один ответ — попытка сдаётся сервером. По умолчанию окно 15 минут; автор меняет в настройках теста рядом с лимитом времени. Сервер сдаёт по дедлайну только свежие сессии: дедлайн плюс льгота прошли не раньше 24 часов назад… Более старые открытые сессии… закрываются close_reason = 'expired' без попытки Неотправленный локальный текст (WAL) не стирается вслепую: модуль сравнивает его с ответами, которые сервер сохранил в попытке…

Сервер сам сдаёт попытку с лимитом, когда ученик не вернулся.

Одна функция сдаёт черновик тем же путём, что ручная сдача.
