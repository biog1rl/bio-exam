<objective>
Фото под сессией ученика: загрузка, список и удаление через один сервис `services/answer-photos` — единственный модуль, который строит ключи `answers/…` и вызывает `storage()` для фото; маршруты в `routes/tests/session-photos.ts` только переводят исходы в HTTP. Плюс файлы фото при удалении пользователя (ADR-0007).

Purpose: критерии 1 (повтор не создаёт дубль, шестое отклоняется, удаление при открытом окне), 2 (WebP без метаданных, 413/415/400 с текстом) и 4 (фото после окна отклонено правилом фазы 11 и не сохранено); PHOTO-02, PHOTO-03, PHOTO-06; D-06…D-10.
Tracer — `uploadAnswerPhoto` клиента (12-06) → `PUT …/photos/:photoId` → сервис → `acceptImage` → хранилище `answers/…` → строка `answer_photos` → 201; список показывает фото. Расширение: инварианты загрузки, удаление, удаление пользователя, снимок маршрутов.
Output: сервис, маршруты, интеграционный тест, монтирование, правка удаления пользователя, помощник теста, снимок.

Правила плана — общие для фазы 12, блок «Правила плана» в `12-01-PLAN.md`.
